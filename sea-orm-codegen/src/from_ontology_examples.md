# Ontology-driven entity codegen — Examples

> **Reference**: integration-plan.md §7 ("Ontology-driven entity codegen")
>
> **SCAFFOLD NOTICE**: These examples document the *intended* behaviour of the
> `--from-ontology` codegen path. The implementation (Sprint 4) will produce
> output matching these examples. Until then the `parse_yaml` and
> `generate_entities` functions in `from_ontology.rs` are stubs.

## Input YAML — Ticket / TicketStatus / TicketMsg

The ontology YAML describes nodes (entities / tables) and edges (relations,
optionally with junction-table properties).

```yaml
# ontology.yaml
nodes:
  - name: Ticket
    pk: id
    pk_type: Uuid
    actor: false          # not an agent; just a plain entity
    columns:
      - { name: subject,    type: String,   nullable: false }
      - { name: body,       type: Text,     nullable: true  }
      - { name: created_at, type: DateTime, nullable: false }

  - name: TicketStatus
    pk: id
    pk_type: i32
    actor: false
    columns:
      - { name: label, type: String, nullable: false }
      - { name: color, type: String, nullable: true  }

  - name: Agent
    pk: id
    pk_type: Uuid
    actor: true           # actor flag: represents a user / system agent
    columns:
      - { name: name,  type: String, nullable: false }
      - { name: email, type: String, nullable: false }

edges:
  # Simple relation — no properties → only generates belongs_to / has_many
  - name: TicketHasStatus
    src: Ticket
    dst: TicketStatus
    properties: []

  # Rich relation — properties present → generates junction entity TicketMsg
  - name: TicketMsg
    src: Ticket
    dst: Agent
    properties:
      - { name: body,      type: Text,     nullable: false }
      - { name: sent_at,   type: DateTime, nullable: false }
      - { name: read_at,   type: DateTime, nullable: true  }
```

## Expected Output — `ticket.rs`

```rust
//! Generated by sea-orm-cli --from-ontology (Sprint 4)
//! Source: ontology.yaml node "Ticket"

use sea_orm::entity::prelude::*;

#[sea_orm::model]
#[derive(Clone, Debug, PartialEq, Eq, DeriveEntityModel)]
#[sea_orm(table_name = "ticket")]
pub struct Model {
    #[sea_orm(primary_key, auto_increment = false)]
    pub id: Uuid,

    pub subject: String,

    pub body: Option<String>,

    pub created_at: DateTime,

    // Relation: TicketHasStatus (simple, no junction table)
    #[sea_orm(belongs_to, from = "ticket_status_id", to = "id")]
    pub ticket_status: Option<super::ticket_status::Entity>,

    // Relation: TicketMsg (via junction table)
    #[sea_orm(has_many, via = "ticket_msg")]
    pub agents: HasMany<super::agent::Entity>,
}

impl ActiveModelBehavior for ActiveModel {}
```

## Expected Output — `ticket_msg.rs` (junction entity with properties)

```rust
//! Generated by sea-orm-cli --from-ontology (Sprint 4)
//! Source: ontology.yaml edge "TicketMsg" (Ticket → Agent with properties)

use sea_orm::entity::prelude::*;

#[sea_orm::model]
#[derive(Clone, Debug, PartialEq, Eq, DeriveEntityModel)]
#[sea_orm(table_name = "ticket_msg")]
pub struct Model {
    #[sea_orm(primary_key, auto_increment = false)]
    pub ticket_id: Uuid,

    #[sea_orm(primary_key, auto_increment = false)]
    pub agent_id: Uuid,

    #[sea_orm(column_type = "Text")]

    pub sent_at: DateTime,

    pub read_at: Option<DateTime>,

    #[sea_orm(belongs_to, from = "ticket_id", to = "id")]
    pub ticket: Option<super::ticket::Entity>,

    #[sea_orm(belongs_to, from = "agent_id", to = "id")]
    pub agent: Option<super::agent::Entity>,
}

impl ActiveModelBehavior for ActiveModel {}
```

## Codegen Rules (implemented in `generate_entities`)

| YAML field        | Generated code                                                         |
|-------------------|------------------------------------------------------------------------|
| `node.name`       | `#[sea_orm(table_name = "<snake_case>")]`, module filename             |
| `node.pk`         | `#[sea_orm(primary_key)]` field; `auto_increment = false` for non-i32 |
| `node.actor`      | Doc-comment annotation only (no structural difference)                 |
| `column.nullable` | `Option<T>` when `true`, plain `T` when `false`                        |
| `edge` (no props) | `belongs_to` on the `src` side; `has_many` on the `dst` side          |
| `edge` (props)    | Junction entity with composite PK + `belongs_to` on both sides        |
| `Text` type       | Mapped to `#[sea_orm(column_type = "Text")]` (MySQL/MSSQL safety)      |
| `DateTime`        | Uses `chrono::DateTime<chrono::Utc>` (default date-time crate)         |
